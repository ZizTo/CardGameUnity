# AI Benchmark: как запускать

Бенчмарк сравнивает варианты минимакса и базовые алгоритмы в автоматическом
режиме. Игровая сцена для запуска не нужна.

## Что изменилось по сравнению со старой версией

- Основной режим — **gauntlet**, а не «все со всеми». Каждый вариант играет
  только с двумя эталонными противниками (`Rule` и `AB-D2`). Это резко
  сокращает число партий.
- Колоды перемешиваются от `seed`, пары партий играются с чередованием
  первого игрока. Результаты воспроизводимы в пределах одной версии Unity.
- Добавлены ограничения времени: на партию и на весь прогон.
- Собираются метрики: winrate, доверительный интервал, среднее время решения,
  число узлов, доля отсечений, попадания в TT, рейтинг Эло.
- `SimGameState.Clone()` больше не использует JSON. Это главное ускорение:
  раньше именно сериализация делала глубину 3–4 почти непригодной для серий
  матчей.

## Запуск из Unity

1. Откройте проект `Game/CardGameUnity` в Unity 2022.3.34f1.
2. Дождитесь компиляции скриптов.
3. Запустите один из пунктов меню:
   - `Tools -> AI Benchmark -> Run Gauntlet` — основной быстрый режим;
   - `Tools -> AI Benchmark -> Run Round Robin` — полный круг, дорого.
4. Результаты появятся в каталоге `BenchmarkResults` в корне проекта
   (`Game/CardGameUnity/BenchmarkResults`).

Можно также добавить компонент `AIBenchmark` на любой GameObject в сцене и
вызвать `Run AI Benchmark` из контекстного меню компонента.

## Запуск в batchmode

Пример для Windows (одной строкой, работает и в cmd.exe, и в PowerShell):

```bat
"C:\Program Files\Unity\Hub\Editor\2022.3.34f1\Editor\Unity.exe" -batchmode -nographics -quit -projectPath "C:\path\to\CardGameUnity" -executeMethod AIBenchmarkRunner.RunFromCommandLine -benchMode gauntlet -benchMatches 6 -benchSeed 12345 -logFile "C:\path\to\unity_benchmark.log"
```

Если запускаете из cmd.exe, можно разбить команду на строки символом `^`.

Параметры:

- `-benchMode gauntlet|roundrobin` — режим;
- `-benchMatches N` — число партий в каждой паре (по умолчанию 6);
- `-benchSeed N` — seed (по умолчанию 12345).

Для полного round-robin начните с `-benchMatches 2`: 12 профилей дают 66 пар,
и полный прогон может занять существенно больше времени.

## Настройки в инспекторе

| Поле | По умолчанию | Смысл |
|---|---:|---|
| `mode` | Gauntlet | Режим построения пар |
| `gauntletOpponents` | Rule, AB-D2 | Эталонные противники |
| `matchesPerPair` | 6 | Партий на пару |
| `maxActionsPerMatch` | 400 | Предохранитель от зависания |
| `maxMatchSeconds` | 30 | Лимит на одну партию |
| `maxTotalMinutes` | 45 | Лимит на весь прогон |
| `randomSeed` | 12345 | Seed колод и MCTS |
| `alternateFirstPlayer` | true | Чередовать первого игрока |
| `useTiebreak` | true | Тай-брейк при исчерпании лимита действий |
| `outputFolderName` | BenchmarkResults | Куда писать результаты |

Если партия не завершилась за `maxActionsPerMatch`, применяется тай-брейк:
сравнивается здоровье героев, затем сила стола. Такие партии помечаются
флагом `tiebreak` в CSV.

## Выходные файлы

- `benchmark_matches.csv` — по одной строке на партию;
- `benchmark_pairs.csv` — сводка по парам;
- `benchmark_summary.csv` — итоговая таблица по вариантам;
- `benchmark_summary.md` — готовая Markdown-таблица для отчёта;
- `benchmark_log.txt` — подробный лог.

## Ожидаемое время

На .NET-прогоне 12 профилей × 2 эталона × 6 партий заняли около 0.2 минуты.
В Unity/Mono время будет больше, но за счёт быстрого `Clone()` и gauntlet-режима
речь идёт о минутах, а не часах. Если на вашей машине прогон всё же долгий:

1. уменьшите `matchesPerPair` до 4 или 2;
2. уменьшите `maxTotalMinutes`;
3. не включайте `roundrobin` для всех 12 профилей без необходимости.

## Соответствие вариантов и профилей

| Короткое имя | Что включает |
|---|---|
| Rule | Жадный rule-based агент |
| MM-D2 | Минимакс без α-β, глубина 2 |
| AB-D2 | α-β + сортировка ходов, глубина 2 |
| AB-D3 | α-β + сортировка ходов, глубина 3 |
| AB-NO-D3 | α-β без сортировки, глубина 3 |
| AB-ID | Итеративное углубление, до глубины 4, 100 мс |
| AB-TT-D3 | α-β + таблица транспозиций, глубина 3 |
| AB-Q-D2 | α-β + quiescence search, глубина 2 |
| AB-PVS-D3 | PVS + TT + сортировка, глубина 3 |
| EXP-D2 | Expectimax с chance-узлами добора |
| PIMC-D2 | PIMC, 6 детерминизаций, глубина 2 |
| MCTS-300 | MCTS, 300 итераций, rollout 6 |
